# Languages (text and audio packs)

Status: in progress (2026-10-16). This file is the contract between the translation data, the engine code and the
menus. Change it only together with the code that reads it.

## User-facing settings

| Cvar | Default | Meaning |
|---|---|---|
| `cod_textLang` | `en` | Language code of the text pack: menus, HUD, hints, briefings, subtitles. |
| `cod_audioLang` | `en` | Language code of the audio pack (voice files). `en` = the game's own audio. |
| `cod_subtitleScale` | `1.0` | Subtitle text size multiplier, 0.5 to 2.5. |

All three are `CVAR_ARCHIVE`, registered in the engine (`qcommon/common.c`, so the UI and cgame both see them), with
first-launch and reset values in `mod/codmod/codmod_defaults.cfg`. Never set them in `codmod.cfg` or `run.sh`.

## Pack layout

A language pack is a directory `lang/<code>/` (lowercase ISO 639-1 code, e.g. `de`, `es`) inside a pk3 named
`codmod_lang_<code>.pk3` in `run/codmod/` (or loose files in the mod dir while developing). Sources live in
`mod/codmod/lang/<code>/` and are packed by `tools/l10n/pack.py`. All files are UTF-8 (no BOM); the engine converts to
the font's 8-bit encoding when it loads them (see "Encoding").

```
lang/<code>/lang.info        pack description (required)
lang/<code>/flag.tga         flag icon, 64x40, 32-bit TGA (required)
lang/<code>/strings.txt      UI/HUD/game string table (text packs)
lang/<code>/subtitles.txt    subtitles, same format as text/subtitles.txt (text packs)
lang/<code>/text/<file>.txt  replacement for text/EnglishUSA/<file>.txt (briefings, notebook, etc.; text packs)
lang/<code>/sound/...        replacement for sound/... voice files (audio packs)
```

English is the base game: `lang/en/` holds only `lang.info` and `flag.tga`; its subtitles stay in
`text/subtitles.txt` (`codmod_subtitles.pk3`).

### `lang.info`

Key/value pairs, parsed with `COM_Parse`:

```
title            "Deutsch"
text             "1"
textDescription  "Mit KI aus dem Englischen übersetzt"
audio            "0"
audioDescription ""
```

`title` and both descriptions are written in the pack's own language. `text "1"` lists the pack in the Texts
selector, `audio "1"` in the Audio selector.

English: title `English`, textDescription `Transcribed with AI from audio files`, audio `1`, audioDescription
`Original game voice recordings`.

### `strings.txt`

One entry per line: the exact English string as the game draws it, then the translation, both quoted:

```
"Subtitles:" "Untertitel:"
"Skip Intro:" "Intro überspringen:"
```

- Lookup is an exact, case-sensitive match on the whole string after the game's own processing (the string passed to
  the text draw function). Colour codes (`^1` etc.) are part of the key and must be kept in the translation.
- Lines starting with `//` are comments. `\n` inside a string is a line break. Use `\"` for a literal quote.
- Strings with a variable part (a key name, a number) are translated as a template: the code looks up the English
  format string (e.g. `"Toggle Flashlight with %s"`) with `Lang_Translate` first, then formats it with `va`. Keep the
  format specifier in the translation. (Example: the one-time flashlight tip in `CG_CodUpdateTips`.)
- A missing entry draws the English string, so partial packs are fine.

### `subtitles.txt`

Same as `text/subtitles.txt`: `path seconds "text"`, keyed by the original English sound path. Lines may be in any
order (the loader sorts them).

## Encoding

Files are UTF-8. The game's fonts are 8-bit (256 glyphs). The loader converts UTF-8 to Latin-1 (ISO 8859-1), which
covers German (ä ö ü ß Ä Ö Ü) and Spanish (á é í ó ú ñ ü ¿ ¡ Á É Í Ó Ú Ñ). If a font has no glyph for a Latin-1 byte,
the engine falls back to the unaccented ASCII letter, so the text stays readable.

## Main menu selector

Bottom-right corner of the main menu, two buttons stacked vertically:

```
[flag] Texts
[flag] Audio
```

Each opens a popup with a scrollable list of the installed packs that have `text "1"` (or `audio "1"`). Each row shows
the flag, the title and the description. Selecting a row sets `cod_textLang` / `cod_audioLang`. Text changes apply at
once (the string table and subtitles are reloaded); audio changes apply on the next map load (or `snd_restart`).
The button labels "Texts" and "Audio" go through `strings.txt` like every other string.

## Building packs

`python3 tools/l10n/pack.py` (or `--lang de` for one) zips each `mod/codmod/lang/<code>/` into
`run/codmod/codmod_lang_<code>.pk3` with paths `lang/<code>/...`; `scripts/install.sh` runs it. Flags are generated by
`python3 tools/l10n/flags.py` (64x40 32-bit TGA, bottom-left origin).

Menu strings that need entries in each pack's `strings.txt`: "Texts", "Audio", "Subtitle Size:", "Back"
(popup button), and the popup titles "Texts" and "Audio".
