# Spanish (es-ES) strings and text files: doubts

Most doubtful first. Files: `mod/codmod/lang/es/strings.txt` (589 entries), `mod/codmod/lang/es/text/*.txt` (206 files, largest 1491 bytes in Latin-1, all under 4000).

1. **Deathshead -> "Calavera"** (user decision) applied in texts and subtitles. Wilhelm Strasse (not Strasser) fixed. "Uber Soldat" kept without umlaut to match the voice-over subtitle; "Supersoldado" for Super Soldier.
2. **maxlen overflows in strings.txt** (menus do not wrap labels; Spanish is longer): "This will apply sound" (14 -> 30 chars), "recommended video settings" (14 -> 29), "and return to the Main Menu." (14 -> 31), "Go to Multiplayer mode?" (12 -> 25), "Exit Menu" (12 -> 14), "DEFAULTS"->"RESTAURAR" (8 -> 9), "LOAD"->"CARGAR", "Load"/"Save" (5 -> 6/7), "(no savegames)" (20 -> 24), "(old savegame)" (16 -> 17), "too hot, no shot" (23 -> 25), the gamepad hint (55 -> 181; English already 163, so the box must clip or wrap). Some English strings already exceed their maxlen, so the limit is unreliable. Needs a visual check in game; shorten the worst ones first.
3. **Date months and "Leveltime"**: months use ENE FEB MAR ABR MAY JUN JUL AGO SEP OCT NOV DIC. The engine matches the whole drawn string, so if a savegame date is drawn as one formatted string rather than month by month these will not match. Verify in the load menu.
4. **Control labels** (Lookup, Strafe, Sprint, ...): Spain-Spanish, but the tutorial texts refer to them in lowercase quotes ('correr', 'saltar', 'agacharse', 'atacar', 'activar', 'patada', 'recargar', 'fuego secundario', 'fuego alternativo', 'acercar zoom', 'recoger objetos auto.'). The menu labels differ slightly ("Correr siempre", "Recoger objetos auto.", "Atacar"). Check that the names match what players see in Controls.
5. **"Lopers" -> "Zancadores"** (invented; the retail Spanish name is unknown). Used in briefings and the Mission 4/5 debriefs.
6. **Names of units and places**: "Guardia Negra" (Black Guard), "Guardia de Élite" (Elite Guard), "Círculo de Kreisau", "Instalación de Armas Secretas (SWF)", "Caballeros Oscuros". Oberst, Oberführer, Hauptmann, Leutnant, Reichsführer, Reichsmarschall, Oberst von Bülow kept in German (umlauts added: Bülow, Führer). "Heinrich I" kept in German form (not "Enrique I"), as the boss name. "Château Schufstaffel" keeps the spelling of the source (Shufstaffel/Schufstaffel are both in the original); I normalised to Schufstaffel. "General von Shurber", "Haupfman/Haupman", "Giereg" kept as in the source.
7. **Re-wrapping**: hard-wrapped pages (res_ pages, Venom manual, objective lists) are re-wrapped at the original maximum line width, so Spanish pages run longer. The ones in the menus with fixed height (objective lists and the notebook res_ pages) may overflow; check a few in game.
8. **Split sentences** (m1_*_br_p2/p3, m2_l4, Zemph diary 3/17 entry, Venom page 6 "...perforaba literalmente la" / "vaina...", res_ "Work" / "was then rapidly resumed", "reduced to no more than" / "45 days"): each fragment is translated so that the concatenation reads as one Spanish sentence; the break point is therefore in a different place than in English.
9. **Handwritten notebook comments** in the res_ pages ("Her again?", "Is that how they refer to me?", "Utter rubbish") are given an informal voice (tú). The Operation Resurrection document uses the formal third person.
10. **Tú vs usted**: briefings use tú toward the player (OSA to B.J.). Letters between Nazi officers use usted, except Strasse to Haupfman (old friends, tú). Deathshead/Calavera uses usted with B.J. in the subtitles (fixed in this pass).
11. **Notebook letters**: "Subject/Subj" -> "Asunto", "To/From" -> "Para/De"; dates "9 de marzo de 1943  21:00", times in 24 h. "Madame Blavatsky" kept in French form in the Operation Resurrection document, "señora Blavatsky" elsewhere.
12. **Imperial/units**: "Seven feet tall" -> "dos metros de altura"; "1/4 inch" kept as "1/4 de pulgada"; 7.92 mm and 0.5 KG use the decimal comma; "100,000 round" -> "100 000 disparos".
13. **Technical terms** in the Venom manual (cerrojo, recámara, desenlazador, alimentador, abrazadera, tuerca almenada, pasador de aletas) are my best guesses; a weapons-literate reader should check them.
14. **Identity entries** left in English on purpose (86 entries): brand/studio names, weapon names (Luger, Thompson, Sten, Colt, Panzerfaust, Venom, Tesla), engine debug strings (MonsterAttack1-3, nopickup(WP_MORTAR)), MSAA/SSAO, numbers, and months identical in Spanish (FEB MAR MAY JUN JUL SEP OCT NOV).
15. **Subtitle fixes applied** from coordinator.md: Katamarunde, Mother Hen -> "Madre Gallina", Caballero Oscuro, "Solo está retrasando lo inevitable", "¿C-c-c-cómo?", "Tendrá que...", "¡Guardias, rápido!", "El americano se ha escapado", "los médicos", "Herr General", Reichsmarschall, Guardia Negra, '38 Latour, Burkhalter, von Stauff, Zemph.
